RAG assistant · Solo

PaperPilot

An ML question-answering assistant that answers only from its knowledge base and checks each answer before showing it.

  • LangGraph agent: query router, ChromaDB retrieval (top 6), cross-encoder reranking (top 3), grounded answer, then an LLM judge that scores faithfulness and retries any answer below 0.7.
  • FastAPI backend with REST and WebSocket streaming, a React dashboard that runs the evaluation suite, and a Streamlit version for the public demo. Docker and GitHub Actions CI.

Result: the judge agreed with all 16 hand-labelled answers. Reranking raised context precision from 0.79 to 0.83, and the retry step raised mean faithfulness from 0.82 to 0.97.

MLOps · Team of 4 · ABB Accelerator 2026

KubeOracle

Predicts which Kubernetes services are likely to fail and shows how a failure would spread, so it can be fixed before it cascades.

  • My part was the MLOps layer: MLflow experiment tracking, a model registry with promote and rollback, PSI and KL-divergence drift checks, and retraining triggered from GitHub Actions.
  • The team's app serves an XGBoost failure classifier from FastAPI, with a React and TypeScript dashboard (service graph, failure simulation, LLM-suggested kubectl fixes) over Prometheus metrics.

Result: 94% F1 on synthetic cluster metrics. It has not been run against a production cluster.

AI study tool · Solo

StudyGenie

Turns a PDF or Word file into a summary, a chatbot that answers from the document, and a quiz.

  • Flask RAG service: extracts text from PDFs, scanned PDFs (Tesseract OCR) and .docx files, splits it into overlapping chunks, retrieves with Sentence-Transformers embeddings plus TF-IDF, and answers through a Groq-hosted LLM using only the retrieved text.
  • PHP and MySQL web app for summaries, chat, MCQ quizzes, study plans and progress charts, with bcrypt passwords and prepared statements. Deployed as one Docker container on Render.
