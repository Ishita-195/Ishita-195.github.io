# Ishita Anand: Portfolio

Personal portfolio site. One static page, no build step.

**Live:** https://ishita-195.github.io/

## Sections

- Hero: role, summary, resume, GitHub, LinkedIn, email
- Projects: four featured projects (PaperPilot, KubeOracle, StudyGenie, ClassLedger) with demo and code links, plus shorter entries
- Experience: IFFCO and AcmeGrade internships
- Skills
- About: education, achievements, certifications
- Contact: links and a message form

## Tech

- Plain HTML, CSS and JavaScript in `index.html`
- DM Serif Display and Inter (Google Fonts)
- FormSubmit for the contact form
- Project screenshots in `screenshots/` (WebP)

## Run locally

```bash
npx serve .
```
